Reading this dashboard. The “What changes” table compares each OFAT value against the block's own reference cell (not the 10-run canonical baseline, except where BA and the reference value coincide) and shades each cell by its own magnitude relative to the largest shift shown in that table — the shading is a visual guide, not a claim about which shifts count as meaningful; that call belongs in the paper text (R2.4: "identify parameters that materially alter magnitudes or ordering" / "state which findings remain qualitatively stable"). No fixed cutoff is applied here on purpose — there's no established convention for a "material" Gini/coverage shift the way there is for, say, Cohen's d, so hard-coding one would just move the judgment call into the dashboard code without making it any more defensible.

Recommendation-volume distributions are shown at full resolution, unbinned, matching the paper's Figure 1 construction exactly — each block/topology's file is fetched only when that view is open (data/pmf/), since all of them together run to tens of megabytes. The Jensen–Shannon/Wasserstein distances come from outputs/sensitivity_analysis/tables/sensitivity_metrics_summary.csv, generated by sensitivity_export_metrics.py. Source tables for everything else: data_sensitivity/<block>/website_data/, generated by ysocial_recsys_reviews.sensitivity.
